# Skydroid's SDK

Put Skydroid's RC SDK here, `rcsdk-v1.9.2.aar` (from https://gitee.com/skydroid/rcsdk-demo,
`app/libs`), then build: the app reads the H12's own sticks, keys and switches. Without it the
app builds as well and drives with a gamepad or the touch sticks. The AAR is Skydroid's,
proprietary: it is not in this repository (`.gitignore`).
